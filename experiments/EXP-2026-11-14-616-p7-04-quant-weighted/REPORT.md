# EXP-2026-11-14-615 — report

P7-04 S4, weighted (imatrix) quantizers. Base commit `b68cffed`; native tree
llama.cpp-flint-cuda `1b44e307`.

## Verdict

ACCEPTED as a port. The weighted arm of `ggml_quantize_chunk` is byte-identical
to the native library for eighteen types, over four imatrix patterns and the
S3b value corpus, at both `-O1` and `-O0`, with 0 failures. The S3b NULL arm
still produces exactly the bytes the accepted S3b port produced. Twelve
mutations of the weighted decisions are caught 6/6 + 6/6.

This closes the S4 requirement of P7-04 once the coverage document and the
ledger are updated by the lead; P7-04 then has S5b (dequant closure) left.

Corpus: 18 types x 4 imatrix patterns (const, ramp, exponential, sparse) x
17 value patterns x block-multiple lengths 32..1024 x 1-4 rows x start
offsets. The NULL arm of the 11 types that have one is compared inside the
same run.

The gate is the only place the imatrix enters: both the port and the oracle
receive the same buffer, so a port that ignored the weights, or used a
different sigma2 factor, cannot pass.
