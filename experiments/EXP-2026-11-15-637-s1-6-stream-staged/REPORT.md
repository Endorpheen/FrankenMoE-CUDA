## 5. How the flag is wired

Two new files in the library, one new CMake block, no edit to any existing
source file.

`common/fg-stream-policy.cpp` — each switched entry point is a two-branch body:

```cpp
int64_t fg_rs_table_verdict(int64_t gathered_refs, int64_t disq_refs) {
#ifdef FG_GOOSE_STREAM
    g_goose_calls.fetch_add(1, std::memory_order_relaxed);
    return rs_table_verdict(gathered_refs, disq_refs);
#else
    return fg_native_rs_table_verdict(gathered_refs, disq_refs);
#endif
}
```

The native half (`fg_native_*`) is the transcription of the runtime's own
function over the same flat arrays, with the native line numbers in the
comment; it is compiled in both configurations and is what the gate compares
against.

`CMakeLists.txt` (staged project):

```cmake
option(FG_GOOSE_STREAM "Select the Goose stream decisions (xl_/dw_/ov_/rs_) ..." OFF)

target_sources(llama-common PRIVATE common/fg-stream-policy.cpp)   # both configurations

if(FG_GOOSE_STREAM)
    add_library(fg-goose-stream OBJECT goose-gen/stream-policy.c)  # one object
    set_target_properties(fg-goose-stream PROPERTIES C_STANDARD 11 POSITION_INDEPENDENT_CODE ON)
    target_compile_options(fg-goose-stream PRIVATE -w)
    target_compile_definitions(llama-common PRIVATE FG_GOOSE_STREAM=1)
    target_include_directories(llama-common PRIVATE ${CMAKE_CURRENT_SOURCE_DIR}/goose-gen)
    target_link_libraries(llama-common PRIVATE fg-goose-stream)
endif()
```

Layout safety: the bridge passes its own `fg_i64`/`fg_u8` (`{pointer, length}`)
straight to the generated C ABI, so `static_assert`s on `sizeof` and both
`offsetof`s compare them with the generated `sl_i64`/`sl_u8` and fail the build
if the module's slice layout ever moves.

On the repository rule "a new feature's flag exists only to disable it": the
staged tree keeps `OFF` as the default so the parity baseline is reproducible
in one command. At integration the default flips to `ON` and the flag keeps
only its disable role; nothing in the bridge depends on the default.

## 6. The gate

`tests/fg_goose_stream_gate.cpp`, built at `-O1` (the repository's gate
convention), links the same `libllama-common.so` the flag built. Each case:
copy the state twice, run the selected implementation on one copy and the
native transcription on the other, compare the return value and every mutated
array byte for byte, print `case=<group>/<name> ret=... digest=... ok=...`.

| group | cases | what is compared |
|---|---:|---|
| `xl_touch` | 12 | return code, `cvalid_`, `cspec_`, list `prev/next`, head/tail, `ever_evicted_`, all five counters |
| `xl_evict` | 11 | evicted id, the list after the unlink, `ever_evicted_`, `cvalid_`, `cspec_`, `cresident_` |
| `xl_budget` | 12 | the budget in force, which entries survived, the list, `cresident_` |
| `dw_subtract` | 12 | output range count and both output arrays (oversized, sentinel-filled, so a stray write shows) |
| `ov_wave` | 12 | pair count and the whole `(projection, expert)` output array, in emission order |
| `rs_verdict` | 12 | the verdict over synthetic reference lists (gather / wrong slot / unmaterialized index) |
| total | **71** | |

Cases are deliberately at the boundaries: an empty cache, a one-element list, a
fused layout with an absent projection, a commit failure, a speculative hit, a
re-read, `budget == 0`, `budget == cresident_`, `budget == cresident_ - 1`, a
zero-length subtraction, adjacent ranges, a single-projection wave, a wave with
every expert hit, expert id 0, and a table whose one non-gather reference
vetoes it.

`goose_calls` is checked, not just printed: the gate counts its own calls to the
selected entry point and requires the bridge's counter to equal it on ON and to
be 0 on OFF, so a lost or doubled dispatch fails the run.

The gate also has teeth: `tests/mutate-stream.sh` mutates the native
transcription seven ways (dropped re-read accounting, unclamped budget growth,
hits emitted as jobs, a closed tail comparison in the subtraction, an ignored
`promote`, a verdict that forgets the veto, a cleared `ever_evicted_`) and each
one fails the gate. Two further candidate mutations turned out to be
semantically equivalent and were replaced; that is recorded here rather than
hidden (see `evidence/gate-selftest.txt`).

## 10. Boundaries: what this stage does not cover

1. **Disk.** No switched decision reads a file. `dw_subtract` is the pure
   complement step used by the oversized hold-back and the row takeover; the
   full complement builder `dw_byte_ranges` (which sorts the expert ranges in
   place) and `DenseWeights`' own read/rebind path are not switched. `pread`,
   `FileReader`, `O_DIRECT` and the lane pool are untouched by design.
2. **Kernel.** `vm_commit`, `vm_evict`, `madvise`, `mincore` and the pinned
   allocator are not called: the commit outcome is an argument
   (`commit_ok`), exactly as EXP621/EXP629 gated it. Nothing here proves that a
   page was actually committed.
3. **Threads.** The switched decisions are eval-thread-only in the native
   source, and the gate is single-threaded. The publishing side of the overlap
   path (mutex, condition variable, `notify_all`, the ready flags) stays
   native, and `ov_stall_*` — the interval state machine whose three integers
   become an `i64[3]` window — is not switched. The generated module has no
   atomics, so `spec_useful_`'s `fetch_add` cannot move with it as is.
4. **Hook region.** None of `rh_` is switched: the topk call ORDER
   (`rh_topk_plan`) is a rewrite of `on_eval`, not a swap, as EXP629 already
   recorded.
5. **Slab plan.** `sp_` (slab geometry, gather plan, eviction guard, the
   materialize limit) is out of this slice; the `rs_` side only uses
   `rs_table_verdict`.
6. **Error and refusal text.** Only the decisions are compared, not stderr:
   a native `fprintf` and a Goose refusal are not the same artefact.
7. **Model-level parity.** Not attempted. No server, no model, no GPU, no tok/s.
   A stage acceptance of "identical model output" is still open and needs
   Igor's explicit approval under rule 1.

## 11. The main seam

The decisions were pure, but their STATE is native object members, and that is
the seam this stage cannot remove: `ExpertStreamSource` holds `cvalid_`,
`cspec_`, `cprev_`, `cnext_`, `ever_evicted_`, `chead_`/`ctail_` and five
counters as private fields of one object; the Goose entry points take seven
flat `i64` slices, a two-element list-head window and a five-element counter
window, and mutate them in place.

So the integration has to choose one of two shapes, and this stage only proves
the cheaper one:

- **mirror** (what the gate does): keep the state in host arrays with the same
  layout the module expects, pass views, and derive the member counters from
  `sacc` after the call. Cost: the arrays are `i64` where the runtime uses
  `int32_t`/`bool` — 8 bytes instead of 1 per flag, about 0.5 MB for a
  61-layer / 256-expert bank, plus one write-back of the counter window per
  call;
- **adapter** (what adoption will need): give the module a narrow state view and
  let it write back into the members, which means the module owns a struct
  definition rather than a slice convention.

Everything else about this slice is small: the module allocates nothing per
call (unlike S1.1's 4.4 MB of schema scratch), and every switched function is a
leaf over integers. The one thing that must not be lost in translation is the
`promote = 0` contract of the overlap path (it re-orders every touched id
afterwards) and the `ever_evicted_` write in evict, which is what makes a
re-read countable.

## 12. What is still open

1. `rh_` order plan (`rh_topk_plan`) as its own integration step; the
   predicates around it (`rh_weights_iso`, `rh_defer`, `rh_close_layer`,
   `rh_observe_weights`) can go one at a time.
2. `sp_` slab plan and the eviction guard, which read `cstamp_` and the
   generation: they need the generation as an argument, as `xl_evict_load`
   already does.
3. `ov_stall_*`: an `i64[3]` window replaces `stall_union.h`'s three integers;
   the mutex and the clock stay in the wrapper.
4. Container widening for the two Go ports that need it (`term_variant_` as
   `std::vector<int8_t>` vs `i64[:]`), which EXP629 flagged and this slice
   avoids by not switching those functions.
5. One-time init: `fg_stream_init()` is the module's `goose_init(0, nullptr)`.
   A production integration must call it from the source's init, once, before
   the first decision — not from a request path.
6. A model-level A/B for the stream path, which is the only thing that can
   promote these decisions from "same answers" to "same tokens".
