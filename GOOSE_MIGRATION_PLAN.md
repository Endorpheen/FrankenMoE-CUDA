# Goose migration record

The staged Flint/llama.cpp migration plan documents the path to standalone
Goose. Its original task sequence and evidence are preserved in
[the migration ledger](docs/goose-migration/tasks.json) and
[the migration archive](docs/goose-migration/INDEX.md). The former full
plan is available in Git as `4c4ad0aef:GOOSE_MIGRATION_PLAN.md`.

For current work, use the [roadmap](ROADMAP.md),
[standalone integration map](integration/README.md) and
[build instructions](docs/BUILD.md). The ledger's task statuses describe
the evidence recorded for their original checkpoints; runtime acceptance is
recorded separately for each model and build.
