## ОЖИДАЕМЫЕ РИСКИ
1. Четвёртый раз подряд инструментирование попадало на неживой путь (диагностика грамматики на
   каждом 200-м вызове, предфильтр на отклоняемой форме, серверный крюк в vendor-копии, крюк
   префикса в неисполняемой перегрузке, нормализация в неиспользуемой сессии). Мера: до написания
   крюка — `strings` по собранной библиотеке, чтение ветви по типу модели, затем прогон.
2. ABI: экспорт принимает структуры по значению; расплющенные пары компилируются и падают при
   входе. Мера: прототип копировать из сгенерированного заголовка.
3. Ложные «зелёные» счётчики: счётчик, полученный некорректным вызовом, хуже красного.
4. Гейт накопительного baseline не может пройти: ожидает libmoe_mmid_tiled.so, которого дерево не
   производит (ядро интегрировано в исходник). Требуется решение: обновить правило гейта либо
   вернуть артефакт.
