## СЛЕДУЮЩИЙ ЭКСПЕРИМЕНТ
Идентификатор: EXP-2026-11-19-1232 — компаратор слияний BPE на живом пути.
Гипотеза: решение о порядке слияний BPE, гейтованное против настоящих очередей, совпадает с
нативным и на реальном словаре; замер — по одному счёту на каждое извлечение из очереди.
Шаги: 1) дверь для компартора в цепочке; 2) крюк в llm_tokenizer_bpe_session::tokenize,
сравнивающий выбранную пару с решением переноса; 3) прогон на Apex, счётчик должен двигаться
тысячи раз; 4) запись результата.
ACCEPT: счётчик двигается и расхождений 0; иначе — разбор направления.

## ОЖИДАЕМЫЕ РИСКИ
1. Измерительный код ошибался чаще порта: за сессию девять ложных тревог против трёх настоящих
   дефектов (DRY, порядок XTC, отсутствующая регистрация хоста). Мера: печатать обе стороны до
   интерпретации числа; сравнивать применениями, а не окнами строк; проверять код возврата
   компилятора напрямую, а не через конвейер.
2. Присутствие символа не равно вызову. Замыкания детокенизатора и GGUF скомпонованы и пока не
   вызываются; таблица в VERIFIED.md различает эти состояния по модулям.
3. Гейт накопительного baseline ожидает libmoe_mmid_tiled.so из experiments/; файл на месте, гейт PASS.
   Если каталог экспериментов будет очищен, гейт упадёт — это ограничение записано.
4. Грамматика остаётся opt-in: корректность доказана (1 736 513 кандидатов + живой тест), стоимость
   11.7x decode не решена; включать по умолчанию нельзя до решения по стоимости.
5. adaptive-p на пути преобразования расходится на 1 ULP в одной вероятности (21 раунд из 100),
   машинерия передачи флага откачена как регрессия. Вне приёмочного профиля.
