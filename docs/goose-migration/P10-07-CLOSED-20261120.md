# P10-07 closed: nlohmann is no longer the default JSON parser

Closed 2026-11-20 on measured evidence, in the order the requirement asks for: a port that answers, a gate
that proves it answered, a live request that cannot tell the difference, and a speed that did not move.

## The artefact

`builds/flint-acc/run-jsondefault` - the baseline `libllama` (200 unit doors) with a `libllama-common`
built from today's sources, where the JSON parser has become the default.

- `verify-candidate`: accepted components **20/20**, 200 doors, 0 duplicate globals;
- `verify-json-build`: door present, adapter present, set self-contained, swap test ok.

## The gate

```
== 1. flag off (FG_JSON_GOOSE_PARSE=0)   json swap: goose=0 texts=21 failures=0
== 2. flag on, strict                    json swap: goose=1 texts=21 failures=0
== 3. strict, no door in the library     refuses, as it must
[exit 0]
```

Twenty-one texts, including escapes, ten-deep nesting, exponent extremes, a repeated key, a `tool_calls`
payload and pretty-printed input. Strict mode makes a decline an error, so mode 2 is the Goose parser
answering, not a fallback.

## What changed in the product

`common_json::parse` now asks the Goose parser first. The switch **disables** it (`FG_JSON_GOOSE_PARSE=0`),
which is the arrangement rule 10 asks for. A build whose library lacks the door still falls back to
nlohmann and behaves exactly as before, so the port's absence is not a failure mode.

## Rollback

`git revert 73c18f3c` restores the opt-in flag; the previous common is preserved in
`builds/flint-acc/run-candidate` and in `Backup/pre-common-rebuild-20261120/`.

## What this does not say

That nlohmann is gone from the tree. It is still linked, still the fallback, and still the answer for any
parse the port declines. The requirement was that the vendored executable dependency stop being the default
path, and that is now true and measured - the removal of the library itself belongs to the later cleanup,
where every remaining caller has to be shown to be unreachable first.
