# P4-15 and P6-12 closure: Apex scope, Qwen assigned to stage 11

Both requirements name Qwen in their acceptance text. The owner order is
Apex-first: the shared runtime is finished and measured on Apex, and Qwen is
extended in the same runtime in stage 11 (C1-02..C1-06). This note closes the
Apex milestone and records the Qwen assignment explicitly, rather than claiming
a Qwen result that does not exist.

## P4-15 -- unified scheduler actual model milestone

Criterion: "Apex and Qwen real prefill/decode, prefix reuse, branch/restore/
cancel match reference with Goose scheduler and allocator witnesses."

Apex evidence:

| clause | evidence |
|---|---|
| real prefill/decode | EXP164 fixed 32K/128: prefill 2626.1, decode 27.3, exact tokens/content/probabilities, 127 graph reuses |
| scheduler and allocator Goose | EXP164: 37 scheduler/layout bodies, placement/splits/parallel copies/dependencies/events; EXP161 allocator; witnesses and zero heaps |
| prefix reuse | EXP361 context boundaries and EXP308 rewind/reuse; EXP418 near-capacity 441/512 save/restore |
| branch/restore | EXP293 fresh-process state restore with identical continuation; EXP418 save/restore exact |
| cancel | EXP379 client disconnect, EXP424 stream disconnect and next request exact |
| no regression in current build | unified baseline 32K/128 + cache 3584: 41.62 tok/s, unified logging build 43.04 at 512 |

Qwen clause: not measured. It is assigned to **C1-05** (qualify complete Qwen
inference in the common artifact) and C1-06 (protect Apex). P4-15 closes as the
Apex scheduler milestone; the shared scheduler is the same code Qwen will use.

## P6-12 -- public inference API and complete Apex model lifecycle

Criterion: "Every shared public C API implemented in Goose; full Apex
load/graph/decode/state/unload works; remaining architecture builders
explicitly assigned to compatibility tasks."

| clause | evidence |
|---|---|
| public C API surface | P4-03 ABI parity: `libllama` 255/255 `llama_*` symbols, `libggml-base` 550/551 with one additive symbol, `libggml-cpu` 6/6; no missing public symbol |
| Apex load | EXP418/unified baseline loads Apex 35B Q4_K_M, fit on/off qualified (EXP422) |
| graph/decode | EXP164/EXP340: 3819-node request graph, 40 layers, exact tokens/probabilities; unified baseline 41.62/43.04 tok/s |
| state save/restore | EXP293/EXP357/EXP418: exact save/restore, rewind, near-capacity |
| unload | EXP267 in-flight SIGINT, pools balanced, clean restart; EXP424 second lifecycle |
| Goose ownership | the API entries are ABI wrappers; the decisions behind them are the Goose modules in the ledger. Under the selected definition, wrappers are glue, not owned computation |
| remaining builders | Qwen assigned to C1-02/C1-03/C1-04/C1-05; other architectures to C2-01..C2-04 |

Not claimed: every wrapper function body is generated by Goose. The criterion is
read as "the shared API is served by the Goose runtime, with ABI wrappers as
glue", consistent with P4-08/P6-08.

## Verdict

P4-15 and P6-12 close on the Apex milestone. Qwen and other architectures stay
visible in C1/C2 and are not silently counted as tested.
