# GooseInfer v0.15.0

Universal x86-64 binaries for Linux and Windows with CUDA and Vulkan backends.

## Linux CUDA verification

RTX 4070, 32,768 prompt tokens and 512 output tokens. Prefill and decode are in tokens per second.

| Model | Prefill | Decode | Output |
| --- | ---: | ---: | --- |
| Apex | 3408.85 | 79.47 | 512 token IDs matched |
| Inkling | 450.67 | 37.12 | 512 token IDs matched in the completed diagnostic run |
| Bonsai MTP | 1003.27 | 72.35 | 512 token IDs matched |
| GigaChat4 | 247.18 | 5.88 | 512 token IDs matched with the GPU expert cache disabled |

The comparable GigaChat4 run with its GPU expert cache enabled was stopped before it reported throughput. Earlier Inkling requests timed out, so the completed run does not establish that the intermittent timeout is resolved. Native Windows CUDA inference and AMD Vulkan performance were not qualified on these artifacts.

These are the existing release candidates. They were built before the integration merge and are published without recompilation. The release uses the explicitly approved mixed toolchain documented in the build guide.
